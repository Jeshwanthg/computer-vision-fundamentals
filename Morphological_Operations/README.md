Morphological Transformations 
---
Overview

This project demonstrates morphological image processing operations using OpenCV with a simple Tkinter GUI.

Users can load an image, adjust kernel size, and apply different transformations.

---

Features:

-  GUI-based image loading
-  Adjustable kernel size
-  Multiple morphological operations
-  Real-time transformation updates

---

Operations Included:


-  Erosion
-  Dilation
-  Opening
-  Closing
-  Gradient
-  Top Hat
-  Black Hat

---

How It Works:
1.  Load an image
2.  Select operation
3.  Adjust kernel size
4.  Apply transformation
5.  View result

---

Run:

python main.py

---

Requirements:

pip install opencv-python numpy

---

Notes:
-  Kernel size affects strength of transformation
-  Works best on binary or high-contrast images
